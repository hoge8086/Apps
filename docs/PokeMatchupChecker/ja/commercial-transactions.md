# 特定商取引法に基づく表示

| 項目 | 内容 |
| --- | --- |
| 販売事業者 | Kenta Hayakawa |
| 運営責任者 | Kenta Hayakawa |
| 所在地 | 消費者から請求があった場合、遅滞なく開示します。開示を希望される場合は、下記お問い合わせ先へご連絡ください。 |
| 電話番号 | 消費者から請求があった場合、遅滞なく開示します。開示を希望される場合は、下記お問い合わせ先へご連絡ください。 |
| お問い合わせ先 | E-Mail: [developer.hoge@gmail.com](mailto:developer.hoge@gmail.com)<br>X: [https://x.com/tcgsim](https://x.com/tcgsim) |
| 販売価格 | 購入手続画面に、月額または年額の税込価格を表示します。価格は利用者の国・地域等により異なる場合があります。 |
| 商品代金以外の必要料金 | インターネット接続に必要な通信料は、利用者の負担となります。 |
| 支払方法 | Apple IDに登録された、App Storeで利用可能な支払方法によります。 |
| 支払時期 | 購入の確定時および各契約期間の更新時に、Apple IDへ課金されます。 |
| 提供時期 | 購入手続の完了後、直ちにプレミアム機能を利用できます。通信状況等により反映まで時間を要する場合があります。 |
| サブスクリプションの期間 | 月額プランおよび年額プランがあります。各プランの期間と価格は購入手続画面に表示します。 |
| 自動更新 | 契約期間終了の24時間以上前までに自動更新を停止しない限り、同じ契約期間で自動更新されます。更新時の課金は、契約期間終了前24時間以内に行われる場合があります。 |
| 解約方法 | iOSの「設定」からApple IDのサブスクリプション管理画面を開き、本アプリのプランを選択して解約してください。本アプリのアンインストールのみでは解約されません。解約後も、支払済みの契約期間が終了するまではプレミアム機能を利用できます。 |
| 返品・キャンセル・返金 | デジタルコンテンツの性質上、提供開始後の返品または交換には応じられません。解約は次回以降の自動更新を停止するものであり、支払済み期間の日割返金は行いません。返金の可否は、法令上必要な場合を除き、Appleの規定および判断に従います。 |
| 動作環境 | App Storeの商品ページに表示します。利用には、対応するiOS端末およびインターネット接続が必要です。 |
| 特別な販売条件 | 未成年者は、保護者その他の法定代理人の同意を得たうえで購入してください。 |
